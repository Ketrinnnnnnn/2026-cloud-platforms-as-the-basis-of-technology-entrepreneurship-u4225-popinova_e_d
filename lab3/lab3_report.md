\## Задачи



1\. Создать Cloud Storage bucket.

2\. Загрузить 3-4 изображения в бакет.

3\. Создать папку и переместить файлы в неё.

4\. Настроить публичный доступ для файлов.

5\. Создать ссылку на файлы.

6\. Удалить созданные ресурсы.



\## Ход работы



\### 1. Создание Cloud Storage bucket



Перешла в раздел \*\*Cloud Storage → Buckets\*\* и нажала \*\*Create\*\*.



\- \*\*Name:\*\* `bucket-kate`

\- \*\*Location type:\*\* Region

\- \*\*Storage class:\*\* Standard

\- \*\*Access control:\*\* Fine-grained



!\[Создание бакета](images/create\_bucket.png)



\### 2. Загрузка изображений



Загрузила 3 изображения в корень бакета через кнопку \*\*Upload files\*\*.



!\[Загруженные файлы](images/upload\_files.png)



\### 3. Создание папки и перемещение файлов



Создала папку `images` через кнопку \*\*Create folder\*\*. Затем выделила загруженные изображения, выбрала \*\*Move\*\* и переместила их в папку `images`.



!\[Создание папки](images/folder.png)



!\[Перемещение файлов](images/move\_files.png)



\### 4. Настройка публичного доступа



Для настройки публичного доступа к файлам:

1\. Перешла в папку `images`.

2\. Выделила файлы, нажала на три точки → \*\*Edit access\*\*.

3\. Нажала \*\*Add principal\*\*, ввела `allUsers`.

4\. Назначила роль \*\*Storage Object Viewer\*\*.

5\. Сохранила изменения и подтвердила \*\*Allow public access\*\*.



!\[Настройка публичного доступа](images/public\_access.png)



\### 5. Проверка публичной ссылки



После настройки публичного доступа в столбце \*\*Public access\*\* появилась кнопка \*\*Copy URL\*\*. Скопировала ссылку и проверила её в браузере в режиме инкогнито — изображение открылось без авторизации.



!\[Проверка первой картинки](images/public\_image\_1.png)

!\[Проверка второй картинки](images/public\_image\_2.png)

!\[Проверка третьей картинки](images/public\_image\_3.png)



\### 6. Удаление ресурсов



Удалила все файлы из бакета, затем папку `images` и сам бакет.



!\[Удаление бакета](images/delete.png)

Была настроена публичная доступность файлов через назначение роли `Storage Object Viewer` для `allUsers`. Получена прямая ссылка на файл, которая работает без авторизации.



\## Выводы



1\. Cloud Storage — это объектное хранилище, которое позволяет хранить и извлекать любые объёмы данных.

2\. Папки в Cloud Storage — это виртуальная структура, реализованная через префиксы в именах объектов, а не отдельные физические сущности.

3\. Для предоставления публичного доступа к отдельным файлам необходимо использовать модель Fine-grained access control и назначать роль `Storage Object Viewer` для `allUsers`.

4\. Публичные ссылки на объекты (Copy URL) работают без необходимости входа в аккаунт Google, что удобно для sharing и тестирования.
